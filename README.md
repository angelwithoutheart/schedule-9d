# Расписание 9Д

Нативное Android-приложение и виджет рабочего стола для расписания ученика 9Д.
Расписание распознаётся с фото через Vision-модель OpenRouter, сохраняется локально
в DataStore и дальше виджет работает полностью офлайн.

## Что умеет

- **Виджет Jetpack Glance** в тёмном минималистичном стиле: статус, номер урока и
  время, крупное название предмета, кабинет.
- **Статусы виджета**: `СЕЙЧАС ИДЕТ`, `СЛЕДУЮЩИЙ УРОК`, `ПЕРЕМЕНА`, `ЗАВТРА`.
- **Точное обновление** в минуты начала и окончания каждого урока и консультации
  через `AlarmManager.setExactAndAllowWhileIdle`. Если разрешение
  `SCHEDULE_EXACT_ALARM` не выдано — используется `setAndAllowWhileIdle`.
- **Смена суток и перезагрузка**: midnight-alarm, `DATE_CHANGED`, `TIME_SET`,
  `TIMEZONE_CHANGED`, `BOOT_COMPLETED`, `MY_PACKAGE_REPLACED`.
- **Приём фото через «Поделиться»** (`ACTION_SEND`, `image/*`): фото сжимается до
  1600 px / JPEG 80 %, отправляется в OpenRouter, ответ парсится в JSON и
  сохраняется на распознанную дату.
- **Постоянные консультации ОГЭ** (вторник, четверг, пятница) с тумблерами и
  редактированием времени и кабинета.
- **Экран приложения**: сегодня и завтра, загрузка фото из галереи, настройки
  API-ключа и модели.
- **Звонки** для будней и субботы зашиты в код.

## Сборка

Требования: JDK 17, Android SDK с платформой 35.

```bash
./gradlew assembleDebug
```

На Windows:

```bat
gradlew.bat assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Путь к JDK 17 закреплён в `gradle.properties` (`org.gradle.java.home`). Если JDK
установлен в другую папку, поправьте этот путь и
`org.gradle.java.installations.paths`.

### `local.properties`

Файл исключён из Git. В нём лежат путь к SDK и ключ OpenRouter:

```properties
sdk.dir=C:/Users/007/AppData/Local/Android/Sdk
OPENROUTER_API_KEY=sk-or-v1-...
```

Ключ попадает в `BuildConfig.DEFAULT_OPENROUTER_KEY` при сборке. При первом
запуске он записывается в DataStore; в настройках приложения ключ можно заменить.
Для публикации приложения в сторе такой способ хранить ключ не предназначен —
ключ извлекается из APK.

## Точные будильники

На Android 12+ приложение запрашивает разрешение `SCHEDULE_EXACT_ALARM` кнопкой
на главном экране. Без него виджет продолжит работать, но обновления могут
задерживаться системой. В Android 14+ разрешение по умолчанию не выдаётся.

## Модели OpenRouter

По умолчанию используются:

1. `google/gemma-4-31b-it:free` — основная;
2. `google/gemma-4-26b-a4b-it:free`;
3. `openrouter/free`.

В запросе передаются `model` и резервный массив `models`. Модель можно заменить
в настройках приложения — тогда она станет основной, а бесплатные модели останутся
резервными. Если перечисленные бесплатные модели недоступны для вашего
аккаунта OpenRouter, укажите в настройках рабочую Vision-модель.

## Структура

```
app/src/main/java/ru/school9d/schedule/
├── ai/                 # OpenRouter-клиент и парсер расписания
├── alarm/              # AlarmManager, приёмники будильников и системных событий
├── data/               # модели, звонки, консультации, DataStore, склейка
├── recognition/        # общий сценарий распознавания фото
├── share/              # ACTION_SEND-активность и её ViewModel
├── ui/                 # Compose-экран и ViewModel
├── util/               # сжатие фото, форматирование, склонения
├── widget/             # Glance-виджет и его приёмник
├── MainActivity.kt
└── ScheduleApplication.kt
```

## Хранение данных

- `DataStore Preferences`, файл `schedule_9d`.
- На каждый день — JSON `SavedSchedule` по ключу `schedule_YYYY-MM-DD`.
- Настройки: `openrouter_api_key`, `openrouter_model`, `oge_consultations`.
- Консультации хранятся отдельно и подмешиваются в конец списка уроков при
  отображении, поэтому их изменение сразу влияет и на приложение, и на виджет.
